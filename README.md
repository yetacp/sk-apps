# Aplicativos StartK

Este repositório contém aplicativos para o runtime corrente do StartK no Kobo Clara BW. Cada pasta é um pacote independente.

| Aplicativo | Propósito |
| --- | --- |
| `basic` | Mostrar os componentes básicos e a navegação do SDK. |
| `calculator` | Realizar cálculos por uma interface de botões. |
| `checklist` | Manter uma lista de tarefas com armazenamento local. |
| `decisions` | Demonstrar diálogos e confirmações. |
| `forms` | Demonstrar campos de texto, escolhas e controles de formulário. |
| `foundations` | Demonstrar a estrutura visual e os controles fundamentais. |
| `ipc-storage` | Exercitar os serviços de arquivos privados e SQLite. |
| `registration` | Cadastrar e consultar registros locais. |
| `values` | Demonstrar indicadores, sliders e seletores numéricos. |

Para criar ou modificar um aplicativo, consulte o [guia de programação Lua](LUA.md).
